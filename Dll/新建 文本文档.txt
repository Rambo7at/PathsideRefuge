### 🏗️ 当前架构关键点

- **主机权威验证 + RPC 广播**，客户端预测表现
- **CreatureBase**：所有生物基类，含伤害网络分层（TakeDamage → ProcessDamage → ApplyDamage）
- **StateMachine**：统一状态机，管理 AnimState/NpcState/PlayerState，含 Stance/Defense 混合参数
- **Equipment**：装备管理组件，字典存储 `Dictionary<E_EquipAVL, ItemData>`，含 RPC 同步
- **ItemData**：物品数据资源，含 E_ItemType/E_EquipType/E_EquipAVL
- **ItemComp**：物品掉落实体，继承 RigidBody3D
- **SlotUI**：UI 格子，委托化数据读写（OnGetItem/OnSetItem/OnDropPos），支持拖拽交换
- **NetSyncBase**：网络同步组件，管理 RPC 注册/调用/场景归属

### 🔧 关键代码规范（AI 必须遵守）

#### 注释风格
```csharp
/// <summary>注：类/枚举/方法说明</summary>
[Export] public int Health { get; set; }  // 属性行尾注释
// 接口实现方法不加注释
```

#### 命名规范
| 类型 | 格式 | 示例 |
|------|------|------|
| 公开属性/字段 | 无前缀，帕斯卡 | `MainHandData` |
| 私有字段 | `m_` 前缀 | `m_Humanoid` |
| 布尔型 | `Is/Can/Has` 前缀 | `IsHost`, `CanStack` |
| 查询方法 | `Get` + 名词 | `GetItemData` |
| 动作方法 | 动词开头 | `TrySetEquipData` |
| RPC 方法 | `RPC_` 前缀 | `RPC_SyncEquip` |
